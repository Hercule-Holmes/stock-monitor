# 股票筛选系统

本地运行的 A 股数据观察与筛选工具。**只做数据观察与筛选,不含任何交易功能。**

核心能力:

- 🔍 **全市场筛选** —— 名称/代码搜索,任意条件组合(跌破 MA120、低于 BOLL 下轨、估值区间、历史分位阈值……),5572 只股票毫秒级出结果
- 📊 **估值与分位** —— PE-TTM / PB / PEG / 股息率 TTM,以及价格、PE、PB 的**全历史分位**(如"现价低于历史 90% 的交易日")
- ⭐ **股票池** —— 多池管理、标签备注、**预期价**,加池自动拉取全历史数据
- 🔔 **个性化监控** —— 规则 = 指标 + 算子 + 阈值,仅监控池内股票;每个交易日中午/收盘两次自动评估;特殊信号(如"达到预期线")可发邮件
- 🧩 **个人指标插件** —— 写一个 Python 函数 + 一行注册,自动成为筛选条件、表格列、监控规则选项
- 📈 **个股详情** —— K线 + MA5~250 + BOLL 叠加、成交量、PE/PB 全历史分位带、分红记录

## 快速开始

```bash
# 1. 安装依赖 (Python 3.12+, akshare 锁定版本)
pip install -r requirements.txt

# 2. 启动 (手动启动,无开机自启;关闭窗口即停止)
python -m app.main        # 或 Windows 双击 start.bat
```

浏览器访问 **http://127.0.0.1:8600**,然后:

1. 「设置」页 → 点「全市场全量更新」(首次约 1.5 小时,一次性)
2. 「股票池」页 → 新建池 → 按代码加入股票
3. 「监控」页 → 添加规则(可勾选邮件提醒)
4. 之后每个交易日 **12:30 / 15:30** 自动更新池内股票并评估规则,全市场数据按需手动更新

## 数据说明

| 数据 | 来源 | 说明 |
|---|---|---|
| 全市场列表 / 盘中快照 | 东方财富 | 盘中快照手动刷新,约 80 秒 |
| 日线(前复权全历史) | 东方财富 | 用于均线 / BOLL / 价格分位 |
| 估值历史 PE/PB/PEG/市销率/市现率 | 东方财富 | 一般自 2018 年起 |
| 股息率 TTM | 新浪分红明细自算 | 近 365 天每股现金分红 ÷ 现价 |
| 历史分位 | 本地计算 | 全历史口径(PE/PB 受数据源限制约 2018 起) |

⚠️ 中午更新时当日 K 线为盘中价,收盘更新后覆盖为正式收盘价。所有数据仅存储在本地 SQLite(`data/stock.db`),不经过任何第三方。

## 架构

```
app/
├── ds.py          数据源适配层 —— 唯一出现 akshare 接口名的地方(接口变动只改这里)
├── indicators.py  指标引擎:REGISTRY 注册表(筛选/表格/规则共用)+ 计算逻辑
├── updater.py     更新任务(全市场/池内/盘中快照)+ 定时调度 + 断点补跑
├── monitor.py     规则评估引擎 + 邮件通知
├── api.py         REST API (FastAPI)
├── db.py          SQLite (WAL 模式)
└── main.py        入口
web/               无框架单页前端 + 本地化 ECharts(不依赖 CDN)
data/              本地数据库(不入库 git)
```

技术栈:Python 3.12 / FastAPI / SQLite / akshare(锁定版本)/ 原生 JS + ECharts。

## 新增个人指标(插件式)

编辑 `app/indicators.py`:

```python
# 1. 写计算函数(输入日线 DataFrame,输出数值)
def my_ind(daily, close, ma120):
    return round(close / ma120 - 1, 4) * 100

# 2. 在 CUSTOM_INDICATORS 注册
{"key": "my_ind", "fn": lambda d, c, m: my_ind(d, c, m)}

# 3. 在 REGISTRY 登记 —— 自动出现在筛选条件/表格列/监控规则三处
{"key": "my_ind", "name": "我的指标", "group": "个人指标", "kind": "value", "fmt": "num2"}
```

重启服务,下次数据更新时新指标自动计算入库。

## 常见问题

**电脑睡眠后数据会漏吗?** 不会。服务启动/唤醒时自动检查数据时效,错过的更新立即补跑。睡眠期间服务暂停是系统机制,唤醒后刷新网页即可。

**为什么不开机自启?** 刻意为之。手动启动(`start.bat`)保证电脑完全在你的控制之下,不会有随开机静默运行的进程。

**换一天没更新会怎样?** 信号按「规则×股票×交易日」去重,补跑后用当日数据重新评估,不会重复也不会遗漏。

**如何配置邮件提醒?** 设置页填入 SMTP 信息(QQ 邮箱:`smtp.qq.com:465` + 授权码),点「发送测试邮件」验证;给需要邮件的规则勾选「邮件提醒」即可。

**akshare 接口变动怎么办?** 所有接口调用集中在 `app/ds.py` 适配层,akshare 升级导致接口改名时只需修改这一个文件。
